# LIA — лендинг

Статический сайт: один `index.html`, без сборки и бэкенда. Внешняя зависимость только Google Fonts.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Весь лендинг: стили, разметка, скрипты анимаций |
| `favicon.svg` | Иконка вкладки |
| `robots.txt` | Разрешает индексацию, указывает на sitemap |
| `sitemap.xml` | Карта сайта для поисковиков |
| `.claude/launch.json` | Локальный сервер для предпросмотра (`npx serve`) |

Следующую версию сохранять так же: папка `v2/` + тег `v2.0`.

## Посмотреть локально

```bash
npx -y serve@14 -l 8787 .
```

Открыть http://localhost:8787.

## Как редактировать

Инструкция для редактора лежит в комментарии в начале `index.html`: тексты правятся прямо в HTML, реплики LIA в примерах переписок печатаются анимацией из того текста, что в разметке.

### Шрифты и отступы

Размеры шрифтов заданы восемью переменными в начале `<style>`: `--fs-display`, `--fs-h2`, `--fs-h3`, `--fs-lead`, `--fs-intro`, `--fs-body`, `--fs-small`, `--fs-micro` (отдельные значения для экранов уже 980px — там же). В элементах размеры не пишутся числами, только `var(--fs-…)`. Исключения: подпись от руки, логотип и большая фраза перед «Кто мы». Отступы секций — `--sec`, `--pad-x`, `--gap`, `--gap-lg`.

## Деплой

Сайт статический, подходит любой статический хостинг: GitHub Pages, Cloudflare Pages, Vercel, Netlify или nginx на своём сервере. Нужно просто отдавать содержимое корня репозитория.

### Перед выкладкой на боевой домен

1. Заменить домен-заглушку `https://lia-ai.ru` на реальный:
   ```bash
   grep -rl 'lia-ai.ru' index.html sitemap.xml robots.txt | xargs sed -i '' 's#https://lia-ai.ru#https://ДОМЕН#g'
   ```
2. Положить `og.png` (1200×630) в корень: это превью при шаринге ссылки в Telegram и соцсетях. Пока файла нет, превью будет без картинки.
3. Заполнить плейсхолдеры `[N]`, `[4,9]` в блоке «Кто мы» и ссылки-заглушки: `#instagram-lia`, `#instagram-est-epil`, `#est-epil`, а в подвале — `#privacy` (политика конфиденциальности), `#terms` (пользовательское соглашение), `#yclients-marketplace`. Эти страницы ещё не написаны.
4. После выкладки добавить сайт в Яндекс Вебмастер и Google Search Console, отправить `sitemap.xml`.

### Что уже сделано для SEO

- `<title>` и `meta description` в пределах лимитов выдачи
- `canonical`, `robots`, `theme-color`
- Open Graph и Twitter Card
- JSON-LD: `Organization`, `SoftwareApplication`, `FAQPage` (дублирует блок «Частые вопросы»: при правке вопросов править оба места)
- `preconnect` к Google Fonts
- один `<h1>`, семантические `<section>`, `<nav>`, `<footer>`, `aria-label`
