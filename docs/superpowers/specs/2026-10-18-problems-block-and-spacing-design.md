# Блок «Что мешает бизнесу расти?», система отступов, шрифт шапки

Дата: 2026-10-18. Тексты лендинга не меняются — только отображение.

## 1. Блок проблем

Порядок внутри секции:

1. `h2` «Что мешает бизнесу расти?»
2. «Кажется, что всё просто:» + **идеальная цепочка** — четыре шага в ряд, все чёрные, точки залитые, стрелка в конце. Линии прорисовываются слева направо при появлении в кадре. Без зачёркиваний, серых шагов и плашки «ответ через три часа».
3. «Но в жизни это выглядит так:» + **сломанная цепочка** — та же сетка:
   - «запустил рекламу» → «гость написал» (подпись `19:12`) — сплошные линии;
   - → «администратор ответил» (подпись `22:40`), линия пунктирная, над ней подпись `через 3 часа 28 минут`;
   - → четвёртый шаг — `«я подумаю»` серым, точка пустая, линия серая пунктирная, стрелки нет.
   Анимация: прорисовка до второго шага обычным темпом, пунктир тянется медленнее, последний шаг появляется серым, подпись «через 3 часа…» всплывает после пунктира.
4. Две колонки: слева **семь болей как карточки-стопка** (белые, скругление как у сообщений чата, `position: sticky` с нарастающим `top`, каждая следующая наезжает на предыдущую); справа — «Переписка студии», липкая, без изменений. На экранах уже 980px карточки идут друг за другом, переписка под ними.
5. Финальные абзацы без изменений.

Подсветка болей серым по мере скролла убирается: карточки всегда читаемы. Связь «скролл болей → анимация переписки справа» сохраняется.

## 2. Система отступов

CSS-переменные в `:root`:

| Переменная | Значение | Где |
|---|---|---|
| `--sec` | `clamp(80px, 9vw, 140px)` | вертикальный паддинг всех секций, светлых и тёмных |
| `--pad-x` | `clamp(20px, 5vw, 64px)` | боковой паддинг секций |
| `--gap` | `clamp(40px, 5vw, 64px)` | заголовок секции → контент |
| `--gap-lg` | `clamp(48px, 6vw, 80px)` | крупные внутренние зазоры |

Исключения с причиной:
- «Что изменится» → «Тогда знакомьтесь»: 24px, это один диалог («Круто?» → ответ LIA).
- Первый экран: свои отступы, не трогаем.
- «Проверено на себе.»: полоса под скролл-анимацию сокращается с `2·X + 60px + 34vh + 48–120px` до `X + 60px + 28vh + --sec`, где X — высота фразы. Тёмный блок по-прежнему наезжает на фразу.
- «Кто мы» (тёмный, наезжает на фразу): `padding-top: calc(var(--sec) + 40px)`.

Разделители «линия + точка» уже стоят между всеми парами светлых секций — не меняются.

## 3. Шапка

`.jh-logo`, `.jh-link`: вес 600 → 500, цвет `#19171C` → `#000`. Кнопка `.jh-btn-in`: вес 600 → 500, фон `#19171C` → `#000`. Логотип в подвале: `letter-spacing` 0.62em → 0.5em, как в шапке.
